# GEM — 宝石の光学スタジオ

**公開アプリ: https://player13579.github.io/gem-optics-lab/**

ダイヤモンド、サファイア、エメラルド、ルビーを回しながら、反射と屈折による輝きを観察する静的 Web アプリです。光の向き・強さ・分散を調整し、3種類のカット、3種類の照明を比較できます。

WebGL 2 で凸多面体に光線を追跡します。スネルの法則、無偏光のフレネル反射、全反射、Cauchy 分散、Beer–Lambert 吸収を用います。静止中は可視光24波長、最高精細では48波長をCIE XYZに積分し、最大128サンプルを積算します。HDRの強い光には光量を再分配するカメラPSFの近似を加えます。近似の範囲と出典は [OPTICS.md](./OPTICS.md) に記載しています。

## 操作

- ドラッグ / 矢印キー: 回転
- スクロール / `+`・`-`: 拡大縮小
- 視点リセットボタン / `0`: 初期視点
- 回転ボタン: 自動回転の切り替え
- モバイル: 宝石を指でドラッグ。設定はビューの下に表示されます。
- モバイルの2本指ピンチ: 拡大縮小
- 描画品質「最高精細」: 48波長、128サンプル、最大40回の内部境界追跡。端末によって仕上がりまで時間がかかります。

最初は静止した状態で細部を積算します。自動回転を止めると再び精細化します。操作中はRGBの高速プレビューへ切り替えます。OS の「視差効果を減らす」設定を有効にすると自動回転も停止します。

## ローカル実行

依存パッケージやビルドは不要です。ES modules を使うため、HTML を直接ファイルとして開かず HTTP で配信してください。

```sh
python -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/` を開きます。WebGL 2 とハードウェア アクセラレーションに対応するブラウザーが必要です。UI の Web フォントが読み込めなくてもシステムフォントで動作します。

```sh
npm test
npm run check
```

ブリリアントは58光学ファセットと16ガードル面の74平面で構成します。スター・ベゼル・アッパーガードル・パビリオン・ロワーガードルの面の接続を凸包の数値テストで検証しています。
